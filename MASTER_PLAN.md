### 📊 BEREICH 2: MetaDesk (Trading)

**Ziel:** Das mächtigste Trading-Intelligence-System der Welt — wie WHOOP aber für Trader.

#### Die 8 Scores (Herzstück):
```
Jeder Score: 0–100 | Farbe: 🔴 Kritisch → 🟢 Stark → 💎 Elite

1. 🧠 Emotion Score      — Wie emotional sind deine Trades?
2. 📊 Consistency Score  — Wie gleichmässig tradest du?
3. 🎯 Discipline Score   — Folgst du deinen eigenen Regeln?
4. 💰 Greed Score        — Nimmst du zu früh Gewinne / hältst zu lang?
5. 😰 FOMO Score         — Springst du auf laufende Züge auf?
6. 🛡️ Risk Score         — Hältst du dein Risikomanagement ein?
7. 🚀 Growth Score       — Verbesserst du dich über Zeit?
8. ⭐ Overall Score      — Dein gesamtes MetaTerminal Trader Rating
```

#### Account Health Predictor:
```
🟢 "Konto Status: Stabil — hält 180+ Tage"
⚠️ "Achtung: Bei aktuellem Verhalten Konto-Blow in ~47 Tagen"
🔴 "KRITISCH: Revenge Trading erkannt — heute aufhören"
```

#### Das Trade Journal:
- **Nur automatisch** — kein manueller Input
- Verbindung über:
  - MT4/MT5 Expert Advisor (EA Download)
  - cTrader OAuth
  - Broker API (Read-Only Key)
  - TradingView Webhook
- **Warum kein manueller Input:** Nutzer könnten lügen → Scores wären wertlos → Verified Badge wäre sinnlos

#### KI News Feed (im Dashboard):
```
JEDER SIEHT:
→ News Headline
→ Quelle + Zeit
→ Betroffene Assets (#EURUSD #Gold)
→ Impact: 🔴 HIGH / 🟡 MEDIUM / 🟢 LOW
→ [🤖 KI Erklärung] Button

FREE NUTZER klickt [🤖]:
→ 🔒 Gesperrt — "Upgrade für KI Erklärung"

BEZAHLTER NUTZER klickt [🤖]:
→ Öffnet sich sofort:
   "Was passiert? Was bedeutet das? Welche Assets?
    Bullish/Bearish? Historischer Kontext?"
→ Je höher das Paket = tiefere Erklärung
```

#### E-Learning:
- Strukturierte Lernpfade (Newcomer → Elite)
- Interaktive Videos (Fragen direkt im Video)
- Guides & Insights Artikel
- Quiz nach jeder Lektion
- XP, Badges, Streak System (Gamification)
- **Learning Impact Score:** Beweist ob Lernen wirkt
  ("Dein Risk Score stieg +37 Punkte nach diesem Kurs")

#### Backtesting:
- **Phase 1 (Launch):** Manual Replay — Chart Bar für Bar vorwärts
- **Phase 2 (Monat 3–6):** Automatisches Backtesting mit Regelwerk
- **Phase 3 (Monat 6–12):** Order Flow Tools (Volume Profile, Delta)

## 🔗 BROKER VERBINDUNG — NUR AUTOMATISCH

```
4 VERBINDUNGS-METHODEN:

1. MT4/MT5 Expert Advisor (EA)
   → Nutzer lädt EA herunter
   → Installiert in MT4/MT5
   → Gibt MetaTerminal API Key ein
   → Alle Trades kommen automatisch

2. cTrader OAuth
   → Login mit cTrader Konto
   → Read-Only Zugriff
   → Automatischer Import

3. Broker API (Read-Only)
   → Binance, Bybit, OANDA, Interactive Brokers
   → API Key + Secret (nur lesen, nie handeln)
   → Automatischer Import

4. TradingView Webhook
   → Webhook URL kopieren
   → In TradingView Alert einfügen
   → Automatische Übertragung

NIEMALS:
❌ Manueller Trade-Input
❌ Schreibzugriff auf Broker-Konto
❌ Geld-Transaktionen
```
